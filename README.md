# Baraa Pratama — Portfolio V4

Personal portfolio website milik **Baraa Pratama**, seorang **Software Developer** dari Jakarta, Indonesia.

Portfolio ini dibuat sebagai personal website untuk menampilkan pengalaman, skills, services, projects, dan contact information dalam satu platform yang modern, responsive, dan professional.

## 🌐 Live Website

https://baraaprtm.vercel.app

## 📦 Repository

https://github.com/baraaprtm/portfolio-v4

---

## ✨ Features

- Responsive design untuk mobile, tablet, dan desktop
- Modern personal portfolio layout
- Home / Hero section
- Services section
- Resume & skills
- Project showcase dengan interactive slider
- Contact form dengan EmailJS
- Social media integration
- Smooth page transitions
- Subtle cinematic animations
- Standalone project pages
- Responsive navigation & mobile menu
